# 学习与实践记录模板

此表用于一次具体学习或实践。复制后填写；不要将“已阅读”与“已验证真实效果”混为一谈。

| 字段 | 记录 |
| --- | --- |
| 日期与学习者 | 待填写 |
| 目标与实际问题 | 待填写 |
| 阶段、课程链接与上游 commit | 待填写 |
| 输入资料与使用范围 | 待填写 |
| 我对原理的解释 | 待填写 |
| 运行环境与版本 | 待填写 |
| 工作目录与运行命令 | 待填写，不记录密钥 |
| 退出码与关键输出 | 待填写 |
| 产物路径或链接 | 待填写 |
| 证据类型 | 概念阅读 / 固定模拟 / 真实模型 / 真实业务数据 |
| 修改了哪个变量 | 待填写 |
| 修改前后结果 | 待填写 |
| 评估集与验收条件 | 待填写 |
| 失败案例与原因假设 | 待填写 |
| 局限与未验证内容 | 待填写 |
| 耗时与费用 | 待填写或标记未测量 |
| 下一步与回查术语 | 待填写 |

## 完成判断

- 能否用自己的话解释机制？
- 能否预测并验证一次小改动的影响？
- 输出和执行证据是否对应当前代码、模型与数据？
- 是否检查了失败、资料不足和边界输入？
- 是否说明了真实调用与教学模拟的区别？
- 是否写明尚未解决的问题，而非只写“完成”？
