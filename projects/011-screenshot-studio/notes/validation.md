## 修正的问题

- 首次离屏导出克隆把画面根节点放在负坐标，产生全透明 PNG。改为离屏父容器，保持捕获节点坐标为零；重新导出并检查像素与成品。
- 标注短文字在导出时意外换行。增加不换行约束与最小宽度，重新导出确认。
- 手机能力按钮横向滚动不够清晰。调整为五等分按钮，背景和窗口控件改为整行。

## 构建环境说明

直接运行 `python scripts/build.py` 时，原有 `_site/demos/008-splat-js/video-assets/source.mp4` 被其他进程占用，导致 Windows 拒绝清理旧输出。没有终止该进程或修改全局构建脚本。

本次使用被 Git 忽略的 `upstream/screenshot-studio-site-check/` 作为独立构建根目录，复用原构建模块和相同项目／Web 源文件，完成清单校验、索引校验及全站生成。随后比较并补齐 `_site` 文件，相同的占用文件无需覆盖。该问题不影响本页独立预览；后续常规清理构建仍需等待视频文件解除占用。
