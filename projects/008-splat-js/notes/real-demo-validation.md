# 真实演示接入与验证

日期：2026-09-08。固定上游版本：128438ac803aacf868938471dcd52f2a16e0d3a6。

## 部署内容

本地部署上游 app/、src/ 与 12 张合成测试图片，保留许可证。首页通过同源 iframe 直接运行应用；不是嵌入视频或用概念动画替代重建。

本地改动限于样例入口、Draft 参数的界面同步、远程数据地址、合成图片路径与字体回退。逐文件核对确认 src/ 数值库与固定上游版本字节一致。静态模块依赖路径检查、项目索引和站点构建检查通过。

| 样例 | 输入与作者结果 | 本次验证 |
| --- | --- | --- |
| Truck | 251 张实拍照片、1,050,000 高斯 | 模型加载成功，显示真实场景；拍摄路径浏览可用 |

## 本机实拍训练

在本地运行器中进入 `?sample=truck`，选择 Draft 并点击 Start training。输入为上游 CDN 的 100 张 Truck 实拍照片；预期配置为 480 像素训练长边、SH 0、10,000 轮、自动高斯预算。默认不留出测试照片。

完整流程运行成功，最终实测结果如下：

| 指标 | 本次实测 |
| --- | --- |
| GPU | NVIDIA GeForce RTX 4070 Laptop GPU，WebGPU 报告架构为 lovelace |
| 浏览器 | Windows / Chrome 152（应用内浏览器） |
| 照片注册 | 100 / 100 |
| 稀疏三维点 | 41,479 |
| 实际迭代 | 10,035（批次提交超过配置的 10,000 停止点） |
| 训练结束高斯数 | 350,000 |
| 训练照片分数 | 29.3 dB（界面显示，非留出测试分数） |
| 纯训练耗时 | 界面约 1 分钟；不包含图片网络加载及相机求解 |
| 导出 PLY | 19,591,896 字节，288,110 个高斯 |

在训练 44% 时，画面已呈现卡车三维外观；最终应用提示结果已保存在本机。通过真实 Export → Download .ply 导出，文件头确认为 binary_little_endian 1.0，包含位置、颜色、不透明度、尺度与旋转字段。导出数量低于训练预算，是因为上游导出流程会过滤几乎不可见的高斯。

导出文件保存在 [truck-draft-100photos.ply](../experiments/results/truck-draft-100photos.ply)。本次未验证第三方查看器重载兼容性。

训练分数不能与作者的留出集分数直接比较，单次本机速度也不代表其他设备。

原始输入只选取完整数据集的一部分；看不到的区域、天空和远景可能有空洞或拉伸。草稿结果用于验证流程，不替代作者长时间训练的高质量样例。
