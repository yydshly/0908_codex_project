查看完整验证结果 ↗
验证能证明什么？

证明被测记忆命令按预期返回结果，不证明关系建议准确。脚本检查来源标签，不独立核验输入是否真实；SQLite 文件没有内置加密。

✓ 未确认时不能启用
✓ 有来源事实可保存并按对象召回
✓ 模型推断不能写成对象事实
✓ 暂停后阻止写入，支持恢复
✓ 撤销写入后，召回内容为空
✓ 清空命令删除测试数据库
